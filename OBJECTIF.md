Je veux créer un blog statique personnel simple, élégant et rapide.

Stack souhaitée :
- Astro
- TypeScript
- Markdown/MDX pour les articles
- CSS simple, sans framework lourd
- Déploiement compatible GitHub Pages ou Vercel

Objectif :
Créer un blog personnel pour partager des geekeries, projets Codex, portages de jeux rétro, bricolages techniques et billets d’humeur.

Fonctionnalités MVP :
- Page d’accueil sobre avec présentation courte
- Liste des derniers articles
- Page blog avec tous les articles
- Page article générée depuis Markdown/MDX
- Tags par article
- Page À propos
- Flux RSS
- Sitemap
- Design responsive mobile
- Support clair/sombre si simple à faire
- Blocs de code bien lisibles

Contraintes :
- Ne pas créer de backend
- Ne pas créer de base de données
- Ne pas ajouter de CMS
- Ne pas sur-ingénierer
- Architecture simple et maintenable
- Code lisible
- Design élégant, sobre, un peu geek/rétro mais pas kitsch

Livrables :
- Créer le projet complet
- Ajouter 3 articles d’exemple
- Ajouter un README avec les commandes npm
- Préparer le déploiement GitHub Pages ou Vercel
