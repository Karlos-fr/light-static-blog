`Carpe diem` signifie souvent « cueille le jour ». Dans ce billet de démonstration, la formule sert surtout de prétexte pour montrer plusieurs blocs Markdown courants.

## Une idée simple

Le contenu peut être structuré avec des paragraphes courts, des intertitres lisibles et quelques éléments de mise en valeur.

- Mettre l’idée principale en premier.
- Ajouter des exemples concrets.
- Garder une progression claire.

> Le Markdown fonctionne bien quand il reste sobre : assez de structure pour guider la lecture, pas assez pour voler la vedette au texte.

## Exemple de code

Voici un petit extrait en JavaScript.

```js
const locution = 'Carpe diem';
const message = `${locution} : écrire une petite chose utile aujourd’hui.`;

console.log(message);
```
