`In vino veritas` signifie « dans le vin, la vérité ». Sans prendre la formule au pied de la lettre, elle rappelle qu’un projet avance mieux quand ses hypothèses sont dites clairement.

## Hypothèses visibles

On peut écrire une hypothèse sous une forme très simple :

> Nous pensons que cette page est utile si elle permet de comprendre le projet en moins de cinq minutes.

Ensuite, il faut décider comment l’observer :

- lire la page à froid ;
- vérifier les liens principaux ;
- relire les métadonnées ;
- tester le rendu mobile.

## Tableau d’observation

| Hypothèse | Signal | Action |
| --- | --- | --- |
| La page est lisible | Lecture rapide | Garder |
| Le chemin est clair | Peu de clics | Simplifier si besoin |
| Le contenu est utile | Exemple concret | Compléter |

La vérité d’un projet est rarement spectaculaire. Elle apparaît souvent dans les détails qu’on accepte de mesurer.
