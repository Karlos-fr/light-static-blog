`Light Static Blog` est une base de blog statique conçue pour publier simplement :
des articles Markdown, quelques images, un flux RSS, un sitemap et des pages HTML
rapides à servir.

Son idée tient en une formule : **festina lente**, se hâter lentement. Le projet
cherche à rester léger, lisible et facile à adapter, sans CMS, sans base de
données et sans mécanique inutile au moment de l'exécution.

Le contenu vit dans des fichiers Markdown. Les thèmes vivent dans des fichiers
CSS. Le build assemble le tout en un site statique prêt à déposer sur GitHub
Pages, un hébergement SFTP ou tout autre serveur capable de servir des fichiers.

Quelques principes guident cette démonstration :

- **carpe diem** : publier sans attendre une architecture trop lourde ;
- **ad astra per aspera** : garder une structure claire pour faire évoluer le blog ;
- **memento mori** : documenter le projet pour qu'il reste compréhensible demain.

Cette page est volontairement générique. Elle peut être remplacée par une vraie
présentation éditoriale dans `src/content/pages/about.md`.
